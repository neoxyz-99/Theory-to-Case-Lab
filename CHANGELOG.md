# Changelog

All notable changes to this project are documented here.

## [Unreleased]

### Changed

- Expanded every reading guide to define `[P]`, `[S]`, `[A]`, `[P/A]`, and `[S/A]` explicitly.
- Added a low-noise provenance policy: label only points of ambiguity, prefer separating source claims from analysis, and reserve combined labels for short inseparable syntheses.
- Extended the validator to reject incomplete evidence legends and warn about excessive paragraph-leading evidence markers.

## [1.0.0] - 2026-08-19

### Added

- Bilingual English and Simplified Chinese theory-reading templates.
- Paired scholarly-reception and application notes with search-scope reporting.
- Optional bilingual Theory-to-Case Lab for concrete cases.
- Distinct causal and interpretive/critical/genealogical/normative pathways.
- `[P]`, `[S]`, and `[A]` evidence-provenance protocol.
- Analytical visual and semantic-emphasis protocol.
- Legacy, paired, and three-file validator modes.
- Synthetic bilingual examples, regression tests, and GitHub Actions validation.

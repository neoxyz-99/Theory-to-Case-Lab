## 1. Scope and queries

Define the theory name, aliases, translations, key concepts, canonical authors, discipline, language, and time window. Use multiple query lanes rather than one broad query:

- `theory + origin/history/genealogy`
- `theory + review/handbook/state of the art`
- `theory + critique/criticism/debate/limitations`
- `theory + revision/extension/reconceptualization`
- `theory + application + domain/population/method`
- `theory + measurement/operationalization/coding`
- `theory + competing theory/comparison/integration`
- key concept combinations without the theory's conventional label

Search in the user's relevant languages when terminology differs across scholarly traditions.

## 2. Build a purposeful source set

Start with canonical texts and reviews, then use references and citations to expand backward and forward. Sample for intellectual positions and application domains, not only high citation counts. For a focused report, favor a defensible representative corpus over an unbounded list.

Tag each item:

- foundation;
- interpretation;
- extension/revision;
- application;
- critique;
- competing account;
- methods/operationalization;
- review/handbook;
- recent frontier.

## 3. Synthesize by problem and position

Build clusters such as:

- stable core and broad agreement;
- rival interpretations of a key concept;
- distinct schools or revisions;
- application patterns;
- empirical support and boundary conditions;
- critiques and responses;
- unresolved questions.

For each cluster, state what is shared, what differs, why it differs, what evidence is used, and what remains uncertain. Avoid an annotated-bibliography dump.

When three or more positions, revisions, or temporal stages would be difficult to compare linearly, use a debate map or timeline under [visual-expression-protocol.md](visual-expression-protocol.md). A visual position must link back to a verified representative source; proximity or arrow direction must not imply consensus, influence, or causation without evidence.

## 4. Map scholarly applications

Classify each use of the theory:

| Use type | Function |
|---|---|
| Direct application | Uses original concepts largely unchanged |
| Operationalization | Converts concepts into indicators, codes, or measures |
| Extension | Adds a concept, mechanism, level, or scope condition |
| Integration | Combines the theory with another framework |
| Critical use | Uses it to expose power, assumptions, contradictions, or exclusions |
| Comparative test/read | Pits it against an alternative explanation or interpretation |
| Background citation | Names the theory without materially using it |

Do not count background citation as substantive application.

## 5. Map controversies precisely

For each controversy, record:

- disputed claim or concept;
- positions and representative sources;
- type of disagreement: factual, conceptual, methodological, normative, interpretive, or scope-related;
- evidence each side accepts;
- whether later work resolves, reframes, or reproduces the dispute;
- consequence for using the theory.

## 6. Derive research paths

Generate paths from documented gaps, not from generic calls for “more research.” Useful paths include:

- untested boundary condition;
- neglected population, setting, period, medium, or archive;
- unresolved concept or translation problem;
- rival mechanisms producing similar outcomes;
- measurement or coding weakness;
- mismatch between theory level and evidence level;
- promising integration with another theory;
- replication or reinterpretation of a canonical case;
- normative assumption requiring explicit examination.

For each path, propose a research question, needed evidence, plausible method, contribution, and main risk.
